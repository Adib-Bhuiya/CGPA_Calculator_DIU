# CGPA Calculator DIU

A simple CGPA calculator designed to help Daffodil International University (DIU) students calculate their semester GPA and track their academic performance.

## Overview

**CGPA Calculator DIU** helps students estimate their academic results by entering course information and grades. The goal is to make GPA calculations easier, faster, and more convenient.

The project is available as a web application, with an Android APK build for mobile users.

## Features

- **GPA Calculation:** Calculate your semester GPA based on course grades and credit information supported by the app.
- **Course Management:** Enter course information to calculate academic results.
- **Quiz Marks:** Account for quiz marks according to the calculator's supported grading rules.
- **Attendance Marks:** Calculate attendance marks based on the entered attendance percentage.
- **Grade Input:** Enter supported grade information to calculate your results.
- **Responsive Interface:** Use the application on desktop and mobile devices.
- **Theme Support:** Switch between light and dark themes.
- **Android Support:** Install and use the Android APK version.

## Getting Started

### Web Application

Open the deployed web application using the link below:

**Live Demo:** (https://cgpa-calculator-diu-adib-bhuiyan.vercel.app/)

### Android Application

1. Visit the [GitHub Releases](../../releases) page.
2. Download the latest APK file.
3. Open the downloaded file on your Android device.
4. Allow installation from that source if Android requests permission.
5. Tap **Install** and launch the application.

> **Note:** Android may display a security warning when installing an APK outside the Google Play Store. Install only a version you trust.

## Important Disclaimer

This project is intended to help students estimate their academic performance. Calculated results may differ from official university results if grading rules, course credits, or entered marks differ from the university's official system.

Please verify important academic calculations against the latest official DIU grading policies.

## Limitations

- Results depend on the accuracy of the information entered by the user.
- The calculator may not cover every possible grading scenario.
- The project may have performance or calculation limitations that will be addressed in future updates.
